## 一、公司速写

三安光电是中国 **LED 芯片 + 化合物半导体** 双龙头，总部厦门。

| 维度 | 概况 |
|------|------|
| 成立 | 2000 年 |
| 上市 | 2008 年借壳（600703） |
| 总部 | 厦门 |
| 定位 | 化合物半导体材料与器件平台 |
| 核心产品 | LED 外延/芯片、SiC 功率器件、GaN 射频、滤波器 |
| 总资产 | 577 亿 |
| 员工 | ~2 万人 |

### 业务拆解：两大板块，一红一蓝

```
三安光电
├── LED 业务（传统基本盘，红海）
│   ├── LED 外延片/芯片（照明、背光、显示）
│   ├── Mini/Micro LED（高端，增量方向）
│   └── LED 车灯（汽车电子）
│
└── 集成电路业务（第二曲线，蓝海）
    ├── 碳化硅（SiC）功率器件 → 新能源车/光伏/充电桩
    ├── 氮化镓（GaN）射频 → 5G 基站/卫星通信
    └── 滤波器（SAW/BAW） → 手机射频前端
```

**核心逻辑**：传统 LED 芯片已是红海（产能过剩、价格战），公司把未来的赌注压在 **SiC（碳化硅）** 上——这是新能源车和光伏逆变器的核心功率半导体材料，需求增速极高。

#### 利润崩塌的解剖

```
FY2024 → FY2025：发生了什么？

营收增长：161.1 → 179.5 亿（+18.4 亿，+11%）
看起来不错？但营业成本：141.9 → 157.2 亿（+15.3 亿，+11%）
→ 毛利：19.17 → 22.32 亿（+3.15 亿，毛利率 11.9% → 12.43%）

但问题出在费用端和其他损失：
  资产减值：-3.315 → -5.262 亿（多亏 1.95 亿）← 存货跌价+设备减值
  投资收益：-0.59 → -2.24 亿（多亏 1.65 亿）
  财务费用：1.80 → 1.81 亿（高负债利息刚性）
  其他收益：9.93 → 7.30 亿（政府补贴减少 2.63 亿）
  
结果：利润总额从 3.58 → -2.01 亿（恶化 5.59 亿）
```

**关键问题**：三安的利润高度依赖政府补贴。2024 年其他收益 9.93 亿（是营业利润的 2.6 倍），2025 年降至 7.30 亿但仍远超营业利润。**扣非净利润连续 6 个季度为负**（2024Q1 → 2026Q1），说明主营业务根本不赚钱。

## 四、行业与竞争格局

### 4.1 LED 芯片：红海挣扎

| 特征 | 现状 |
|------|------|
| 行业格局 | 三安+华灿+乾照，产能严重过剩 |
| 价格趋势 | 通用照明芯片持续跌价 |
| 增量方向 | Mini/Micro LED、车用 LED |
| 三安优势 | 规模第一，但利润极薄 |

> LED 芯片是"现金牛"变"现金消耗"。高端化（Mini LED）是出路，但增量不增利。

### 4.2 SiC 碳化硅：关键胜负手

| 维度 | 现状 |
|------|------|
| 市场需求 | 新能源车 800V 平台 + 光伏逆变器 → 爆发式增长 |
| 竞争格局 | Wolfspeed/意法/英飞凌 vs 三安/天科合达/天岳先进 |
| 三安进度 | 长沙/重庆 SiC 产线，产能爬坡中 |
| 核心问题 | **良率低 → 成本高 → 亏损 → 等待规模效应** |

```
SiC 赛道的残酷真相：
- Wolfspeed 也亏损（全球龙头都亏）
- 中国的 SiC 衬底价格已从 2023 年的 $800/片降到 $400/片
- 三安的 SiC 业务处于"卖了就亏，不卖更亏"的尴尬阶段
- 等待新能源车 800V 渗透率突破临界点（目前 ~15%）
```

### 4.3 滤波器：红海中的红海

- 手机射频前端，博通/高通/Qorvo 垄断
- 国产替代逻辑成立，但卓胜微/好达/三安都在做
- 价格战激烈，短期难以盈利

## 八、核心矛盾与关键跟踪指标


## 九、总体评价与投资启示

### 一句话总结

> **三安光电是一个"故事足够大、现实足够惨"的化合物半导体平台公司。SiC 的产业趋势没错，但公司自身的财务健康度和治理风险已经到了需要高度警惕的程度。**

### 三种情景推演

| 情景 | 概率 | 催化剂 | 股价方向 |
|------|:--:|------|:--:|
| 🟢 SiC 扭亏 + 大股东问题解决 | 20% | SiC 大单/良率突破/800V 渗透加速 | ↑↑ |
