## 二、价值投资双框架定位

| 框架 | 判定 | 证据 |
|------|:----:|------|
| **长线价投**（垄断/定价权/持续性） | ✅ **基本符合** | 垄断性 ✅（派格宾慢乙肝临床治愈无国内直接竞品，毛利率 96.3%）；定价权 ✅（医保谈判前净利率 27.9% 且毛利率 93% 稳定 3 年）；持续性 ✅（慢乙肝需长期用药 + 益佩生打开第二曲线） |
| **景气价投**（宏观/天花板/增速确定性） | ✅ **符合** | 天花板 ✅（慢乙肝 8000 万+携带者 + 生长激素市场）；增速确定性 ✅（6 年净利 CAGR 58.8%，一致预期 2026-2028 +21%/+27%/+23%）；宏观 = 医保支付（集采是主要变量） |

**这是三家里唯一同时满足"垄断性 + 定价权 + 持续性"的标的**——但它的客户是患者/医院，商业模式是**卖药**，与另两家的"卖试剂/原料"完全不同，周期属性也更弱。

### 第三步：资产负债表

**杜邦（2025）**：ROE 34.83% ＝ 净利率 27.9% × 周转 0.85 × 权益乘数 1.47 → **高 ROE 来自高净利率 + 高周转 + 适度杠杆**，是三家里财务结构最健康的。

- 2026H1 销量：抗病毒用药 **521.41 万支（+26.9%）**、血液/肿瘤 1,263 万支、内分泌 36.25 万支

### 5.2 核心逻辑

1. **派格宾 = 慢乙肝临床治愈赛道垄断者**：中国慢乙肝表面抗原阳性者约 8,000 万，临床治愈（功能性治愈）是新共识，派格宾是核心治疗手段之一，无国内直接竞品，毛利率 96.3%。
2. **益佩生 = 长效生长激素第二曲线**：2026 年医保落地，正面切入长春高新/安科生物主导的短效生长激素市场，**以"周制剂"替代"日制剂"**（对患者依从性是降维打击）。

## 七、风险清单

1. **派格宾依赖度 83.6%**：单品集中。若慢乙肝临床治愈方案被新技术替代（如反义寡核苷酸 Bepirovirsen 等口服/注射新机制药物），将直接冲击核心收入。
2. **生长激素集采预期**：益佩生虽新上市暂不集采，但长春高新/安科短效生长激素已受集采重创，整个赛道的医保预期压制估值。
3. **2026Q1 增速转负的教训**：益佩生放量投入 + 研发引进费用化可能在未来季度重现，单季利润波动加大。
4. **应收账款 11.28 亿**（占营收 30.5%）：医药商业渠道账期长，现金流持续弱于利润。
5. **二股东通化东宝（10.29%）**：历史渊源股东，存在减持或同业竞合的不确定性。
6. **股东户数半年 +58.7%**（6,677 → 10,580），同期股价 -38%——**下跌中散户接盘、机构（华夏科创50ETF、东方红）退出**，筹码结构恶化。
7. **医保谈判降价**：派格宾/益佩生均需在医保目录动态调整中让利，净利率（27.9%）有下行压力。

## 九、结论

### 9.1 框架判定

| 维度 | 结论 |
|------|------|
| 商业模式 | ⭐️⭐️⭐️⭐️ 卖药（派格宾慢乙肝垄断 + 益佩生第二曲线），毛利率 93% |
| 成长性 | ⭐️⭐️⭐️⭐️ 6 年净利 CAGR 58.8%，2026E +21% 的"放缓"是投入期扰动 |
| 利润质量 | ⭐️⭐️⭐️⭐️ 扣非 > 归母，利润全来自主营 |
| 估值 | ⭐️⭐️⭐️⭐️ 16.4x 2026E / 12.9x 2027E，PEG 0.66，股息率 4% |
| 综合 | **三家里唯一"好公司 + 合理偏便宜的价格"** |

### 9.2 一句话

> **特宝生物是三家里唯一同时具备"垄断（派格宾慢乙肝临床治愈无竞品、毛利率 96.3%）+ 成长（6 年净利 CAGR 58.8%）+ 便宜（PE 2026E 16.4x、PEG 0.66、股息率 4%）"的标的，而且扣非 > 归母，利润全部来自主营。它的下跌（YTD -38%）不是因为基本面坏了，而是 2026Q1 一次性的投入费用 + 生长激素集采情绪 + 机构换仓。Q2 已经用 +27% 的归母增速证明了自己。风险在于：83.6% 收入押在派格宾一个药上、应收 11.28 亿、以及生长激素的集采预期。**

### 9.3 跟踪清单

1. **Q3 单季归母增速**能否维持 +25% 以上（验证 Q2 恢复的持续性）
2. **益佩生（生长激素）**医保放量节奏（第二曲线成败）
3. **派格宾**集采/医保谈判动态
4. 应收 11.28 亿的周转是否改善
5. 通化东宝（二股东 10.29%）是否减持

### 9.4 操作建议

| 情形 | 动作 |
|------|------|
| 当前位置 51.50 元 | **可分批建仓观察**（16.4x 2026E + 4% 股息 + PEG 0.66，三家里性价比最高） |
| 加仓条件 | Q3 归母增速 >25% 且益佩生放量超预期 |
| 减仓条件 | 派格宾被新机制药物替代的临床数据出现 + 生长激素集采落地 |
