# 十倍股跟踪系统

> 基于"渗透率跟踪 + 信号评分 + 全球信息差套利"的十倍股研究辅助工具

## 快速开始

```bash
cd stock-tracker

# 每天早上第一步 —— 十倍股候选筛选（CAN SLIM 七维，自动识别最新财报期 + 今日市值）
python3 tenbagger.py

#   常用参数：
#   --grow-years 3         连续N年营收&净利从未下滑（默认3，含当期共4年）
#   --min-grow 10          每年营收增速下限（默认0=只要不下降）
#   --accelerating         额外要求增速逐年抬升（加速型，可选）
#   --max-gain-low 1.0     可选"起点"过滤：从低点涨幅≤100%（默认不过滤，只在表里显示）
#   --require-rs 80        L: 只留近似RPS≥80（CAN SLIM 及格线）
#   --require-inst 1.0     I: 只留公募基金持股≥1%
#   --strict-market        M: 空仓期（指数跌破50日线）直接退出，不输出候选

# 每天早上第二步 —— 全球信息差扫描（发现一手海外信号）
python3 discovery.py scan

# 每天早上第三步 —— 5 分钟了解今天该关注什么
python3 tracker.py daily

# 发现新信号时 —— 录入到系统中
python3 tracker.py update

# 每周/每月跑一次 —— 查看完整评估和推荐
python3 tracker.py review

# 财报季（1/4/7/10月）—— 扫描财报关键词
python3 tracker.py earnings
```

## 命令一览

| 命令 | 用途 | 建议频率 |
|------|------|---------|
| `tenbagger.py` | 🌟 十倍股候选每日筛选（小市值+次新+**一贯增长**+扣非干净，低点涨幅只作展示） | **每天** |
| `discovery.py scan` | 🌍 全球信息差扫描（RSS+关键词） | 每天 |
| `daily` | 每日检查清单 | 每天 |
| `update` | 录入新信号 | 发现信号时 |
| `review` | 完整评估报告 | 每周/每月 |
| `earnings` | 财报关键词扫描 | 财报季 |
| `add` | 添加新标的 | 需要时 |
| `edit` | 编辑/删除标的 | 需要时 |
| `discover` | tracker.py 内调用 discovery | 每天 |
| `discovery.py source` | 管理信息源 | 需要时 |

## 财报季筛选三件套 🆕

财报季（1/4/7/10 月）全市场量化筛选，实现 `earnings-season-keyword-screening` skill 的完整漏斗：

```bash
# 1. 全A股"双40%"筛选（营收 & 净利增速 > 40%）
#    → 输出：行业聚类（板块效应）+ 完整池 CSV
python3 screen_h1.py                                  # 2026中报，双40%
python3 screen_h1.py --rev 30 --profit 50             # 自定义阈值
python3 screen_h1.py --date 20260630 --keep-bj        # 保留北交所

# 十倍股起点口径：小市值 + 次新 + 连续多年高增长
python3 screen_h1.py --date 20260930 --rev 30 --profit 20 --rev-years 2 \
    --mcap-min 30 --mcap-max 100 --min-listing 1 --new-listing 3
#   --mcap-min/--mcap-max  总市值区间（亿，腾讯行情实时取）
#   --min-listing/--new-listing  上市年限区间（年）
#   --rev-years N  要求连续 N 年（含当期）营收增速都 ≥ --rev

# 加速型曲线口径：营收增速逐年抬升（捞"乔锋类"曲线）
python3 screen_h1.py --date 20260930 --rev 20 --profit 20 --accelerating \
    --accel-gain 20 --mcap-min 30 --mcap-max 80 --min-listing 1 --new-listing 5
#   --accelerating  增速逐年非递减 + 首末差 >= --accel-gain
#   --accel-years   用几个历史年报点（默认3，含当期共4点，如 2023→2024→2025→当期）
#   输出表带"增速曲线(旧→新)"列，直接肉眼看曲线形态

# 2. 关键词扫描（巨潮资讯全文检索，7 个关键表述 → 信号分）
#    → 自动与双40%池取交集
python3 keyword_scan.py
python3 keyword_scan.py --sdate 2026-10-01 --edate 2026-10-31   # 三季报季

# 3. 扣非校验（剔除靠一次性收益撑起来的高增长）
python3 kf_check.py out/keyword_cross_2026-07-01_2026-09-20.csv
```

**漏斗**：全A 11450 → 双40% 901 → 剔亏损/小规模 332 → 关键词命中 184 → 扣非达标 151

| 脚本 | 数据源 | 核心能力 |
|------|--------|---------|
| `screen_h1.py` | 东财业绩报表 + 腾讯行情 | 全市场一次拉完；行业聚类看板块效应；标记"小基数"（利润增速>1000%）与现金流告警（现金比<0.3）；支持市值区间 / 上市年限 / 连续 N 年增速过滤 |
| `keyword_scan.py` | 巨潮全文检索 | 15 个关键词跨全部公告检索；按公告类型分级（中报正文 > 业绩预告 > 调研纪要） |
| `kf_check.py` | 同花顺财务摘要 | 扣非增速 + 非经常性损益占比；判定 ✅真主营增长 / ⚠️非经常占比高 / ❌扣非大降 |

产出目录 `out/`，网络缓存 `.cache/`。

**注意**：增速是筛选器，绝对额才是判断依据。利润增速 >1000% 多为低基数幻觉；周期股（锂/钨/锡/航运）高增长来自价格而非份额，不属于成长股范畴。


## 🌟 tenbagger.py：CAN SLIM 七维筛选

只筛财报（C/A）会挑出"报表漂亮但股价不动"的票。完整版按欧奈尔 CAN SLIM 七维：

| 维度 | 含义 | 脚本实现 | 数据源 |
|:--:|---|---|---|
| **C** | 当季收益 | 营收&净利同比 ≥ `--rev/--profit` | 东财业绩报表 |
| **A** | 年度收益 | 连续 N 年营收 ≥ `--min-grow`、净利 > 0 | 历年年报 |
| **N** | 新事物 | L2 认证等基本面催化需人工判断；股价新高看"距MA200" | — |
| **S** | 供需 | 流通盘/融资余额/股东户数（表内 `低点涨` 辅助判断弹性） | 腾讯行情 |
| **L** | 领涨股 | 近似 RPS（60日 60% + 年初至今 40%，全市场分位） | 全A行情 |
| **I** | 机构认同 | 公募基金持股占总股本%（取最近完整披露期） | 东财机构持仓 |
| **M** | 大盘方向 | 上证/创业板/沪深300 相对 MA20/50/200 + MA50斜率 | 指数日K |

### M 是一票否决

脚本每次运行**先打印 M 状态**：

```
🔴 上证指数   3649.18  MA20 3693.30  MA50 3821.37↓  MA200 3984  距50日线  -4.5%
🔴 创业板指   2465.23  MA20 2648.26  MA50 3053.03↓  MA200 3465  距50日线 -19.3%
🔴 沪深300   4054.28  MA20 4112.86  MA50 4351.23↓  MA200 4637  距50日线  -6.8%

【M 大盘方向】🔴 空仓期 —— 全部指数跌破 50 日线，本清单仅建池不建仓
```

- 三大指数**全部**跌破 MA50 → **空仓期**，输出仅作建池，不做建仓建议
- 加 `--strict-market` 则直接退出不输出
- 全部站上 MA50 且 MA50 上翘 → 上升趋势，可满仓

### 表格里的 L/I 列怎么读

| 标记 | 含义 |
|---|---|
| `L:RPS ≥ 80` | 🔥 相对强度合格（CAN SLIM 买入区间），`< 50` 为 ⚠️落后 |
| `I:公募% ≥ 1` | 有主动机构认同；`< 0.5` 标记 ❗机构缺失（无机构愿意重仓） |
| `⭐干净` | 毛利≥25 + 现金≥0.3 + 扣非占比≥0.9 + ROE≥5 |

**推荐组合**：`--require-rs 80 --require-inst 1.0` —— 只在 M 允许的行情下使用，这批才是 CAN SLIM 意义上的"可买标的"。全部为空时，说明当前市场没有"既强势又被机构认同"的小盘成长股，**这本身就是一个有价值的信号**。


## 信号评分体系

每个信号有不同权重（1-5 分），得分越高表示正面信号越多：

| 分数 | 建议 |
|------|------|
| ≥ 20 且 S 级 | 🔥 强烈关注-买入候选 |
| ≥ 12 且 S 级 | ⭐ 重点研究-等待加仓 |
| ≥ 12（非 S 级） | 🔔 信号强烈-可考虑升至 S 级 |
| ≥ 6 | 📋 常规跟踪 |
| < 6 | ⏳ 等待信号 |

## 核心理念：三级信号发现体系

```
[第一级] 全球信息差套利（discovery.py）
  英文行业期刊 → RSS + 关键词扫描 → 提前 2-8 周发现信号
          ↓
[第二级] 财报季关键词筛选（tracker.py earnings）
  业绩大增 + "供不应求/高景气度"关键词 → 验证第一级信号
          ↓
[第三级] 成长股真伪鉴定（growth-stock-authentication skill）
  3-5 年增速趋势 + 三张表交叉验证 → 确认买入
```
